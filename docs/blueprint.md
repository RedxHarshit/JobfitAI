# **App Name**: JobFit AI

## Core Features:

- AI Resume Parsing: Parse and analyze resumes to extract relevant skills and experience using Gemini, forming the basis for unbiased candidate evaluation. This serves as a tool for subsequent shortlisting.
- AI Candidate Matching: Match candidates to job descriptions based on skills, experience, and potential using AI. Focus on contextual understanding and transferable skills. This is achieved by Gemini reasoning about the job description to make a decision.
- AI Interview Insights: Generate interview questions and talking points for recruiters based on a candidate's profile and job requirements, enabling more effective and insightful interviews. Gemini is employed as a tool, drawing information from prior steps to prepare the best questions.
- Candidate Profile UI: Display candidate profiles with extracted skills, experience, and AI-generated insights for recruiters to review.
- Secure Authentication: Securely manage recruiter access and candidate data using Firebase Authentication and Security Rules.

## Style Guidelines:

- Primary color: A vibrant blue (#29ABE2) to represent intelligence and innovation, while avoiding cliches such as Teal. It contrasts effectively with a light background, ensuring visibility and creating a modern, professional feel.
- Background color: A very light blue (#E0F7FA) to provide a clean and professional backdrop.
- Accent color: A contrasting green (#90EE90), analogous to blue, to highlight key actions and information. It provides a visual cue without overwhelming the primary color scheme.
- Clean and readable sans-serif font.
- Simple and modern icons to represent different skills and job functions.
- A clean and intuitive layout with clear sections for candidate information and AI insights.
- Subtle animations to indicate loading states and highlight key interactions.
